Keep D01–D26 in filenames, for example `D03-select-and-filter.md`; use `W02-...`, `A01-...` and `P01-...` for weekly sets, assignments and practicals. These are naming examples, not existing files.

Each session's lab is done after class to practise that day's ideas; it is not submitted or graded. Solutions are shown in class and are not posted in this repository. Assignments keep their published due dates. Editable slide sources are kept privately; only PDF slides are published.

Each lab will state prerequisites, input/version, numbered steps, three checkpoints, expected output, a self-check and a fallback. Shared datasets live once in [shared/datasets/](../../shared/datasets/README.md); link to them rather than copying them between modules.

Solutions are not published here. Keep keys and instructor notes in the local ignored `instructor/` folder or the approved private teaching store. Graded submissions go to the institution’s private collection route, not issues or pull requests in this course repository.
