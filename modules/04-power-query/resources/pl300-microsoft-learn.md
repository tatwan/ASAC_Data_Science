# PL-300 and Microsoft Learn: free reading for the Power BI weeks

The Power BI weeks prepare you for **PL-300, Microsoft Power BI Data Analyst**. Microsoft publishes what the exam tests and a free course that follows it. Use the course modules as reading before or after each session; they use Microsoft's own sample data, so the screens look a little different from ours.

## What the exam tests

Skills measured as of 20 April 2026 ([study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/pl-300)):

| Part of the exam | Weight | Our sessions |
|---|---:|---|
| Prepare the data | 25–30% | D16, D17 |
| Model the data | 25–30% | D18, D19, D20 |
| Visualize and analyze the data | 25–30% | D21, D22 |
| Manage and secure Power BI | 15–20% | D23 |

## Desktop or the browser

- **Power BI Desktop** runs on Windows 10 or later ([get Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop)). There is no Mac version.
- **In the browser** (`app.powerbi.com`), you can upload a CSV or Excel file to **My workspace**, which creates a semantic model, and build a report on it ([create a report from a file in the service](https://learn.microsoft.com/en-us/power-bi/create-reports/service-report-create-new)). You can also edit the semantic model there, including **Transform data** in Power Query ([edit semantic models in the service](https://learn.microsoft.com/en-us/power-bi/transform-model/service-edit-data-models)).

## Your licence

| Licence | What it lets you do |
|---|---|
| Fabric (Free) | build reports for yourself in **My workspace**; no sharing |
| Power BI Pro | shared workspaces, sharing and apps |
| Premium Per User (PPU) | Pro plus most Premium features |

Find yours in `app.powerbi.com` under your profile picture → **Account manager**. If **Start trial** or **Free trial** appears, the trial gives you 60 days with the rights of a Premium Per User licence ([Fabric trial](https://learn.microsoft.com/en-us/fabric/fundamentals/fabric-trial)), unless your university has switched trials off. More: [Power BI licence types](https://learn.microsoft.com/en-us/power-bi/fundamentals/service-features-license-type).
