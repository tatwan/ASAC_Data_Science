# Activity 03 · Green, amber, red

In this activity, you will sort ten things an analyst might do with an AI assistant by how risky each is for a client. Work with a partner if you can; it also works alone.

**Files:** this page.

**Data:** none.

## The three levels

| Level | Meaning |
|---|---|
| **Green** | Fine as it is |
| **Amber** | Fine only with a check, a disclosure or a permission |
| **Red** | Do not do it |

Two questions sort most cases: **what am I sending**, and **who relies on the answer**?

## Instructions

1. Read each scenario and mark it green, amber or red.
2. For every amber, write what would make it green.
3. For every red, write a safer way to get the same help.

| # | Scenario | Level |
|---|---|---|
| 1 | You ask an assistant to explain how a LEFT JOIN differs from an INNER JOIN. | |
| 2 | You paste a Power Query error message. It contains no data. | |
| 3 | You paste a client's customer list, with names and phone numbers, to get the city names cleaned. | |
| 4 | You paste the column names and three rows you made up, and ask for the cleaning steps. | |
| 5 | You ask an assistant to draft the email that reports your findings, using numbers you already checked. | |
| 6 | You paste the client's quarterly results, which are not published yet, to get a summary for the board. | |
| 7 | You put a DAX measure the assistant wrote into the client's report, after it matched a total you know. | |
| 8 | You let an assistant choose which customers get their credit limit cut. | |
| 9 | You paste a connection string that contains the database password, to debug a refresh. | |
| 10 | You upload the client's sales file to a business assistant your employer has approved. | |

## Check yourself

You should have **3 green, 3 amber and 4 red**. The sorted list is shown in class and is on the slide "Activity 03: the ten scenarios sorted".

## Hint

The four things that never go into a prompt: client data, personal data, secrets, unpublished figures.

## Bonus

Write an eleventh scenario from your own work or studies and ask your partner to sort it.
