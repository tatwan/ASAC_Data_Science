# Module 01 · Data foundations

[Course home](../../README.md) · [Schedule](../../course/STUDENT_SCHEDULE.md) · [Assessment](../../course/ASSESSMENT.md)

**Week 1 · D01–D02 · 20 and 21 September 2026 · 8 hours**

This week you learn to read a table before you query it, and to turn a vague business question into
something you can actually count. No SQL yet. By Sunday your three tools are working and you have
seen, once, what the rest of the programme is building towards.

## D01 · Sunday 20 September

Where this work sits in the job market, how the programme runs, and the part that starts today:
what one row of a table represents. Grain, candidate key, dimension, measure, and the quality
problems you can see without any tool. Then the three tool checks, together.

Files: [table-reading worksheet](labs/W01-table-worksheet.pdf) ([xlsx](labs/W01-table-worksheet.xlsx)) ·
[setup checklist](resources/W01-setup-checklist.pdf) ([xlsx](resources/W01-setup-checklist.xlsx)) ·
[w01_retail data](datasets/w01_retail/)

## D02 · Monday 21 September

Where data actually lives. Transactional against analytical systems, database against warehouse
against lake, and what ETL and ELT mean. Then BigQuery itself: projects, datasets, tables, schema,
preview, and your first query on a public table.

## Homework

[Week 1 homework](assignments/W01-homework.md) — get BigQuery, GitHub and Power BI Desktop working.
About 90 minutes. Due before 2:00 PM on Sunday 27 September, at the start of D03.

It is the only homework this week, and it is not graded. D03 teaches SQL and assumes you can reach
BigQuery, so a tool that will not open is the one thing that can cost you a session.

## Set up your tools

| Tool | Where to go | Notes |
|---|---|---|
| BigQuery Sandbox | [cloud.google.com/bigquery/docs/sandbox](https://cloud.google.com/bigquery/docs/sandbox) | Free, no credit card. Sign in with any Google account. If it asks for a card, stop and tell us |
| GitHub | [github.com/signup](https://github.com/signup) | Free. Pick a username you would show an employer |
| Power BI Desktop | [microsoft.com/power-platform/products/power-bi/downloads](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) | **Windows only.** On a Mac or Linux, do not try to install it — record it on your checklist and we arrange a machine |
