# Week 1 homework

[Module home](../README.md) · [Course home](../../../README.md) · [Assessment and deadlines](../../../course/ASSESSMENT.md)

**Due: before 2:00 PM on Sunday 27 September 2026 — one week after D01, at the start of D03.**
**Time: about 90 minutes, most of it waiting for downloads.** Not graded. It is checked.

There is one job this week: get BigQuery, GitHub and Power BI Desktop working on your own machine.
SQL starts on D03 and it assumes you can reach BigQuery. If something will not work, the point of
doing this now is that we find out while there is still a week to fix it.

> tonight costs you nothing. The same account fixed next Saturday costs you the SQL session.

> **Never put a password, a verification code or a recovery answer in a screenshot or anywhere in
> this homework.** Crop them out. Nobody on the programme team will ever ask you for one.

## 1 · BigQuery Sandbox · about 20 minutes

1. Sign in with a Google account. A personal account is fine. Create a free one if you do not have one.
2. Open BigQuery Sandbox. **It should never ask you for a credit card or a billing account.**
3. Open any public dataset and preview one table.

**Evidence:** one screenshot of the preview, with the table name visible.

**If it asks for a card or a billing account,** stop. Do not enter one. Screenshot the message,
write the time on your checklist, and post in the channel.

## 2 · GitHub · about 15 minutes

1. Create a free account. Choose a username you would be content to show an employer.
2. Create one repository called `asac-sql-portfolio`. Public. Tick the box to add a README.

**Evidence:** the repository URL.

You do not need Git installed yet, and you do not need to put anything in the repository. We build it
together on D08.

## 3 · Power BI Desktop · about 45 minutes, most of it downloading

**Power BI Desktop runs on Windows only.** If your machine is a Mac or runs Linux, **do not try to
install it.** Write that on your checklist instead. There is a lab machine route and we arrange it for
you; you have lost nothing.

On Windows:

1. Download Power BI Desktop from Microsoft and install it.
2. Open it once and let it finish its first-run setup.

**Evidence:** one screenshot of Help, then About, showing the version number.

**If the installer asks for administrator rights you do not have,** record that. It is a normal
situation on a shared or work machine and it has a solution, but only if we know.

## 4 · Update your checklist · about 10 minutes

One row per tool. Each row either says it works, or records the exact error text and the time you saw
it. A recorded blocker is a complete answer. A blank row is not.

The returned checklists are how we find out, before D03, who has no Windows machine and whose
BigQuery account is blocked. That is the whole reason this is the only homework in week 1.
