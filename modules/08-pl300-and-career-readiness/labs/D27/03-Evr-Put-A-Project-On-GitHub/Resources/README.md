You may copy these files into your own repository to practise.

**Data.** `penguins.csv` holds the Palmer penguins: Gorman, Williams and Fraser (2014), *PLoS ONE* 9(3): e90081, from the [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/) package, licence [CC0](https://creativecommons.org/publicdomain/zero/1.0/). 344 rows; two have no measurements. The SQL reads the same data from BigQuery's public table `bigquery-public-data.ml_datasets.penguins`.
