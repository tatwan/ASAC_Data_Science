# GitHub words in plain language

| Word | What it means | A way to picture it |
|---|---|---|
| **Git** | The program that records every saved version of a folder | The rule that every page is dated and none is torn out |
| **GitHub** | A website that stores folders recorded with Git, so others can see them and work on them | A library where the notebooks are kept |
| **Repository** (repo) | One project: its files, its folders and its history | One notebook |
| **README** | The file GitHub shows on a repository's front page | The cover text |
| **Markdown** | Plain text with a few marks, such as `#` and `**`, that GitHub draws as a page | Writing with simple formatting marks |
| **Commit** | One saved version, with a message, a time and the name of who made it | One dated page |
| **Commit message** | The short sentence that says what changed | The title of that page |
| **History** | The list of all commits | The table of contents |
| **Diff** | What one commit changed: removed lines in red, added lines in green | Corrections in two colours |
| **Branch** | A separate copy of the project where you can make changes safely | A draft |
| **`main`** | The branch visitors see first | The final copy |
| **Issue** | A note about something to fix or add | A sticky note |
| **Pull request** (PR) | A request to bring the changes from a branch into `main` | "Please look at my draft" |
| **Merge** | Accepting the pull request | Copying the draft into the final copy |
| **Fork** | Your own copy of someone else's repository | Photocopying a notebook to write in |
| **Clone** | A copy of a repository on your own computer | Taking a copy home |
| **Star** | A bookmark for a repository | A shelf of favourites |
| **GitHub Pages** | A free website made from the files in a repository | A shop window |
| **Profile README** | The README GitHub shows at the top of your profile | Your CV |
